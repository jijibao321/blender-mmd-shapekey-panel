# Blender MMD 形态键面板与面部控制器


一款专为 MMD（MikuMikuDance）模型设计的 Blender 增强工具。它不仅能将零散的日文形态键（Shape Key）整理为清晰的中文分类面板，更提供了一个**可自由拖拽、并能完美跟随 MMR 控制器移动的 3D 视图嘴型操控板**，让角色口型动画变得直观且高效。

---

##  主要特性

- **智能分类面板** – 在 3D 视图右侧 N 面板中，将形态键分类陈列，告别混乱的列表。
- **中文名称映射** – 自动将日文形态键转换为易懂的中文名称（如 `闭眼`、`微笑`），降低使用门槛。
- **一键插入关键帧** – 每个形态键旁都配有“K帧”按钮，调整数值后点击即可快速记录动画关键帧。
- **3D 视图嘴型控制器** – 在角色头部附近生成一个半透明的 2D 控制面板。通过拖拽面板上的方块或滑块，即可实时驱动 `A / I / U / E / O` 五个元音的形态键，实现“所见即所得”的口型塑造。
- **智能 MMR 跟随（无缩放扭曲）** – 控制面板可选择跟随 MMR（MikuMikuMoving）的控制器对象或特定骨骼。采用 **Child Of 约束**实现跟随，彻底规避了直接设为子级时因父级缩放导致面板位置严重偏移的问题。
- **灵活的别名匹配系统** – 支持通过预设别名（如 `mouth_a`、`あ`、`a`）自动匹配模型中的形态键，无需手动绑定。

---

##  安装

1. 下载 `mmd_shape_key_panel.py` 文件。
2. 打开 Blender，进入 `编辑 > 偏好设置 > 插件`。
3. 点击 `安装...`，选择下载好的 `.py` 文件。
4. 在插件列表中勾选 **"MMD Shape Key Panel and Face Controller"** 启用。
5. （可选）安装完成后，3D 视图右侧 N 面板会出现 **"MMD 形态键"** 标签页。

---

##  使用方法

### 一、形态键分类面板（基础功能）

1. 在 Blender 中选中你的 MMD 模型网格（Mesh）。
2. 按 `N` 键展开右侧工具栏，切换到 **"MMD 形态键"** 选项卡。
3. 你会看到按“眼睛”、“嘴”、“眉毛”等分类好的形态键列表。
4. 拖动滑块调整数值，或点击右侧的 **黄色菱形图标** 插入关键帧。

### 二、视图表情控制器（进阶功能）

此功能可在 3D 视口中生成一个直观的嘴型操控板，适合在动画制作中快速调节口型。

#### 1. 创建控制器
- 在 **"MMD 形态键"** 面板中找到 **"MMD 视图表情控制器"** 折叠区域。
- **角色 Armature**：选择 MMD 模型的骨架（Armature）。插件会自动扫描其子级中带有形态键的网格。
- **MMR 跟随目标（可选）**：
  - 若要让面板跟随 MMR 的控制器移动，在 *"控制器对象"* 栏选择对应的 MMR 空对象或骨架。
  - 如果选择的是骨架，可在 *"控制器骨骼"* 栏填写具体的控制骨名称（例如 `CTRL_Head`），留空则跟随骨架整体。
- 点击 **"创建视图表情控制器"** 按钮。

#### 2. 操控方式
创建成功后，角色附近会出现一个带有 **5 个元音标记**的 2D 面板：
- **A 滑块**：水平拖拽下方的方块，控制 `A` 口型的张开程度。
- **I / U / E / O 方块**：在方框区域内拖拽中心的蓝色方块。方块越靠近对应字母的边缘，该元音形态键的强度就越高。

#### 3. 管理控制器
- **重置方块**：一键将控制方块复位到面板中心位置。
- **删除 / 重建**：可以随时删除控制器及其自动生成的驱动程序。若勾选 *"重建已有控制器"*，再次点击创建将自动覆盖旧版。

## 自定义修改（进阶）

如果你需要**调整分类**或**修改中文显示名称**，只需在插件源码开头的字典中增删条目即可：

- **分类集合**：`EYE_KEYS`、`MOUTH_KEYS`、`BROW_KEYS`、`OTHER_KEYS`，按集合语法添加或删除日文原名。
- **中文映射**：`DISPLAY_NAME_MAP` 字典，格式为 `"日文原名": "中文显示名"`。

修改后重新加载插件（或重启 Blender）即可生效。

---

## 注意事项

- 插件仅对 **网格（Mesh）** 类型物体生效，请确保选中身体网格而非骨架。
- 形态键名称必须**与表格完全一致**（包括数字、特殊符号），否则不会被正确分类。
- 若模型没有任何形态键，面板会提示“请选择一个带有形态键的网格物体”。
- 本插件不修改模型本身，所有操作均可撤销。
